# 模板目录

模板匹配(W4)使用的模板图片统一放在本目录。

## 规范

- 命名:`<用途>_<说明>.png`,如 `death_dialog.png`、`combat_on.png`
- 来源:必须在真实游戏窗口中截取,禁止手绘或凭空生成
- 分辨率:与实际运行的游戏客户端分辨率一致;更换分辨率需重新截取
- 记录:每个模板建议在文件名或本文件中注明截取时的客户端分辨率
